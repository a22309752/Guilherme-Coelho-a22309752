Sobre esta aplicação

1. Arquitetura MVT do Django

Esta aplicação foi desenvolvida em Django, utilizando a arquitetura MVT: Model, View e Template.

  • Model: representa os dados da aplicação e está definido no ficheiro models.py.
  • View: contém a lógica da aplicação e está definida no ficheiro views.py.
  • Template: corresponde aos ficheiros HTML apresentados ao utilizador.

O fluxo começa quando o utilizador acede a uma URL. O Django procura essa URL em urls.py, chama a view correspondente, a view pode ir buscar dados aos models e depois envia esses dados para um template, que gera a página HTML final.

2. Modelação

A aplicação utiliza vários modelos Django para representar os dados do portfólio. Cada classe definida em models.py corresponde a uma tabela na base de dados.

  • Licenciatura: guarda informação sobre o curso.
  • Docente: guarda informação sobre docentes.
  • Unidade Curricular: representa cadeiras do curso.
  • Projeto: representa projetos desenvolvidos.
  • Tecnologia: representa tecnologias usadas nos projetos.
  • TipoTecnologia: permite classificar tecnologias por tipo.
  • Competência: representa competências adquiridas.
  • Formação: representa formações realizadas.
  • MakingOf: regista o processo de desenvolvimento.
  • TFC: representa trabalhos finais de curso.

Existem relações entre os modelos. Por exemplo, um Projeto pertence a uma Unidade Curricular e pode estar associado a várias Tecnologias e várias Competências.

4. Estrutura das páginas

A aplicação possui várias páginas principais: Home, Licenciatura, Projetos, Tecnologias, TFC, Making Of, Competências e Formações.

Algumas páginas permitem operações CRUD, ou seja, criar, editar e apagar informação, como Projetos, Tecnologias, Competências e Formações.
